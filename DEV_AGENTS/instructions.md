# Agent Instructions

## Task

1. Create a file called `readmeAgent.md` in the repository root.
2. Write a short introduction about yourself in it — what you are (an AI coding agent), what tools you used, and a timestamp of when you created the file.
3. Stage and commit the file with a descriptive commit message.
4. Push the current branch to the remote (`git push -u origin HEAD`).
5. Open a pull request against `master` using the `gh` CLI (`gh pr create --fill`).
6. Checkout back to `master` (`git checkout master`).

## Constraints

- Do NOT modify any existing files — only create the new `readmeAgent.md`.
- Keep the PR title and body concise.
- Do not merge the PR, just open it.

## Files of interest

- `readmeAgent.md` (the file you will create)
